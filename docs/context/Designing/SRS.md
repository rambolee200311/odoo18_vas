## 1 业务背景与目标

### 1.1 业务背景

仓库日常运营中，除标准入库、出库操作外，存在大量库内增值作业（如贴标、缠膜、简单组装、分拣等）。当前增值作业无统一业务记录单据，依赖纸质或口头交接，无法按操作员统计作业量，与业务订单无法关联追溯，现场作业凭证无统一归档。

### 1.2 当前问题

- 问题 1：增值作业无系统化记录，依赖纸质/口头交接，信息易丢失
- 问题 2：无法按操作员统计作业量（数量/工时），缺乏数据支撑
- 问题 3：增值作业与业务订单（入库/出库）无法关联追溯
- 问题 4：现场作业凭证（图片/视频）无统一归档，异常时难以查证

### 1.3 业务目标

- 目标 1：建立统一的库内增值作业单，记录每一次增值作业的业务事实
- 目标 2：实现增值作业与业务订单的关联绑定，支持业务追溯
- 目标 3：每张作业单绑定唯一操作员，支持多人作业分别建单、分别记录作业事实与作业量
- 目标 4：支持现场快速录单（PDA）与内勤查询管理（Web）两种业务场景
- 目标 5：按需留存作业凭证，满足质量追溯与异常核查需要

### 1.4 顶层产品约束

- 约束 1：本期仅形成基础作业数据，不负责绩效规则、工资或奖金计算
  → 含义：系统不得内置任何绩效计算、费率、工资相关的业务逻辑
- 约束 2：作业单是业务事实记录单据，非审批流单据
  → 含义：系统不内置审批环节；提交即确认，错误通过反提交回到草稿修正
- 约束 3：PDA 与 Web 共用同一业务模型，仅交互方式不同
  → 含义：不得为 PDA 和 Web 分别建立独立的业务数据模型

## 5 功能需求

### 5.1 作业单创建与编辑（Web + PDA）

**FR-VAS-01 创建作业单（草稿）**

- 触发条件：仓管员或主管登录系统，进入作业单新建页面
- 业务行为：填写表头信息（关联对象、关联单据号、操作员），添加至少一条作业明细行（操作类型、数量/工时、备注），按需上传图片/视频
- 业务结果：系统生成唯一作业单号，记录创建时间，单据状态为「草稿」
- 异常/边界：关联对象为入库/出库时，关联单据号必须对应有效单据，否则禁止保存；其他订单时单据号不得为空但不要求绑定实体

**FR-VAS-02 添加/删除作业明细行**

- 触发条件：在作业单编辑页面，用户点击【+新增作业行】或【-删除选中行】
- 业务行为：新增行选择操作类型后系统自动带出单位；删除行移除选中明细
- 业务结果：明细行数量 ≥ 1 时允许提交；= 0 时禁止提交
- 异常/边界：至少保留 1 条明细方可提交；删除最后一条时系统提示禁止

**FR-VAS-03 选择关联对象与录入关联单据号**

- 触发条件：用户在表头选择关联对象（入库订单/出库订单/其他订单）
- 业务行为：入库/出库时录入或扫描关联单据号，系统校验有效性；其他订单时录入线索号
- 业务结果：关联对象与单据号绑定到作业单
- 异常/边界：无效单据号予以提示，禁止保存

**FR-VAS-04 选择操作员（代录）**

- 触发条件：用户在表头选择操作员
- 业务行为：从允许参与当前仓库作业的人员范围内选择实际操作员
- 业务结果：作业单记录该操作员为唯一作业人员
- 异常/边界：提交人可与操作员不同（允许代录）

**FR-VAS-05 上传附件（选填）**

- 触发条件：用户在附件区选择图片/视频文件
- 业务行为：上传文件至作业单
- 业务结果：附件与作业单关联，可在详情页查看
- 异常/边界：非必填；支持多文件；文件格式和大小限制由配置控制

### 5.2 作业单提交、反提交与作废

**FR-VAS-06 提交作业单**

- 触发条件：用户在草稿状态下点击【提交】
- 业务行为：系统校验所有阻断规则（BR-VAS-01~05），校验通过后锁定核心字段
- 业务结果：状态变为「已提交」，记录提交时间和提交人，核心字段不可再修改
- 异常/边界：校验不通过时禁止提交，提示具体违反的规则

**FR-VAS-07 反提交作业单**

- 触发条件：用户在已提交状态下点击【反提交】
- 业务行为：系统解锁核心字段，允许修改
- 业务结果：状态变为「草稿」，核心字段恢复可编辑
- 异常/边界：仅「已提交」状态允许反提交；已作废状态禁止反提交

**FR-VAS-08 作废作业单**

- 触发条件：用户在草稿状态下点击【作废】
- 业务行为：系统标记单据为「已作废」
- 业务结果：状态变为「已作废」，不可修改、不可恢复
- 异常/边界：仅「草稿」状态允许作废；已提交状态禁止作废

### 5.3 作业单查询与查看

**FR-VAS-09 查询作业单列表（Web）**

- 触发条件：用户进入作业单列表页面
- 业务行为：按单号、关联对象、关联单据号、操作员、时间、状态等多条件筛选
- 业务结果：返回匹配的作业单列表，显示摘要信息
- 异常/边界：无匹配时返回空列表

**FR-VAS-10 查看作业单详情**

- 触发条件：用户点击列表中的作业单行
- 业务行为：展开查看完整表头、明细行、附件
- 业务结果：展示所有字段，系统字段只读
- 异常/边界：附件仅在详情页查看

## 6 业务规则

| 编号 | 规则描述 | 作用级别 | 关联需求 |
|------|----------|----------|----------|
| BR-VAS-01 | 一张作业单仅对应一个操作员；不同操作员的作业必须分别建单 | 阻断 | FR-VAS-01, FR-VAS-04 |
| BR-VAS-02 | 一张作业单至少包含 1 条作业明细；支持一单多作业 | 阻断 | FR-VAS-02 |
| BR-VAS-03 | 关联对象固定三选一：入库订单、出库订单、其他订单 | 阻断 | FR-VAS-03 |
| BR-VAS-04 | 入库/出库订单的关联单据号必须对应系统有效单据；无效禁止保存 | 阻断 | FR-VAS-03 |
| BR-VAS-05 | 其他订单的关联单据号不得为空，但不要求绑定实体单据 | 阻断 | FR-VAS-03 |
| BR-VAS-06 | 单据提交后核心业务信息锁定，不可直接修改；仅允许通过反提交回到草稿后修改 | 阻断 | FR-VAS-06, FR-VAS-07 |
| BR-VAS-07 | 已提交状态的作业单禁止直接作废 | 阻断 | FR-VAS-08 |
| BR-VAS-08 | 仅草稿状态允许作废；作废后不可恢复，仅保留审计 | 阻断 | FR-VAS-08 |
| BR-VAS-09 | 草稿状态下所有可编辑内容可反复修改 | 提示 | FR-VAS-01 |
| BR-VAS-10 | 数量/工时为单一数值字段；单位由操作类型决定，系统自动带出，无需人工填写 | 推荐 | FR-VAS-02 |
| BR-VAS-11 | 录单人可代其他实际操作员登记，但必须记录真实实际操作员；提交人和操作员可不同 | 提示 | FR-VAS-04 |

### 6.1 业务异常 vs 基础设施异常

| 类型 | 含义 | 业务处理 |
|------|------|----------|
| 业务异常 | 输入不合法、规则不满足（如无效单据号、明细为空）等业务层面可预期的问题 | 系统提示具体错误信息，禁止对应操作（提交/保存），由用户修正后重试 |
| 基础设施异常 | 系统故障、网络中断、服务不可用等技术层面的问题 | 系统提示通用错误信息，记录留痕；用户可重试或联系管理员；不影响已提交数据的完整性 |

## 7 状态与生命周期

### 7.1 状态定义

| 状态 | 业务含义 | 可进入条件 | 可执行动作 |
|------|----------|------------|------------|
| 草稿（Draft） | 尚未正式形成作业事实记录，所有可编辑内容可反复修改 | 新建作业单；或已提交状态执行反提交 | 修改内容、提交、作废 |
| 已提交（Submitted） | 已正式确认，核心业务内容锁定，不可直接修改 | 草稿状态执行提交 | 反提交（回到草稿）、查看 |
| 已作废（Cancelled） | 原业务记录失效，历史保留仅用于审计追溯 | 草稿状态执行作废 | 仅查看，不可恢复 |

### 7.2 状态流转

| 当前状态 | 动作 / 条件 | 目标状态 | 关联需求 |
|----------|-------------|----------|----------|
| — | 创建 | 草稿 | FR-VAS-01 |
| 草稿 | 点击【提交】 | 已提交 | FR-VAS-06 |
| 已提交 | 点击【反提交】 | 草稿 | FR-VAS-07 |
| 草稿 | 点击【作废】 | 已作废 | FR-VAS-08 |

### 7.3 禁止流转

| 编号 | 禁止规则 |
|------|----------|
| BR-VAS-07 | 已提交状态禁止直接作废（必须先反提交到草稿，再作废） |
| BR-VAS-08 | 已作废状态禁止恢复或反提交（终态） |
| — | 已提交状态禁止直接修改核心字段（必须通过反提交） |

## 附录 A 术语表

| 术语 | 定义 |
|------|------|
| 增值作业（VAS） | 仓库内除标准入库/出库外，为客户提供的附加服务（如贴标、缠膜等） |
| 作业单 | 记录一次完整库内增值作业业务事实的单据 |
| 作业明细 | 作业单中的单行作业记录，包含操作类型、数量/工时、单位 |
| 关联对象 | 作业单所关联的业务单据类型（入库订单/出库订单/其他订单） |
| 反提交 | 将已提交的作业单退回到草稿状态，允许修改后重新提交 |
| 代录 | 录单人替实际操作员创建作业单，提交人与操作员不同的场景 |
