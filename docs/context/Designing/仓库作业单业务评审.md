# 仓库作业单业务评审定稿文档

**文档定位**：供仓库操作人员确认表单字段、布局、现场操作逻辑，为业务评审定稿文档，非开发SRS。

## 核心已定业务口径（本次评审基准）

1. 一张作业单仅对应一个操作员；不同操作员作业需分别建单，同一份业务订单可关联多张作业单。
2. 一张作业单支持录入多条作业明细（一单多作业）。
3. 图片/视频为选填凭证，按需上传。

---

## 一、单据字段总览表

### 表头（整张单据公共信息）

| 字段名称 | 录入方式 | 是否仓管填写 | 说明 |
| :--- | :--- | :--- | :--- |
| 作业单号 | 系统自动流水生成 | ❌不填 | 自动唯一编号，人工不可修改 |
| 关联对象 | 下拉选择 | ✅填写 | 可选：入库订单 / 出库订单 / 其他订单 |
| 关联单据号 | 扫码二维码 / 手工输入 | ✅填写 | 扫描或输入关联业务单号，系统识别并绑定对应业务单据，无效单号予以提示 |
| 图片/视频 | 文件上传/拍照 | ⚠️选填 | 作业凭证，根据现场实际情况选择上传，支持多个图片、视频 |
| 操作员 | 人员选择 | ✅填写 | 实际执行本张作业单所登记作业的仓管；一张作业单只对应一个操作员 |
| 提交人 | 系统自动 | ❌不填 | 点击【提交】时自动记录当前登录账号，不可修改 |
| 新增时间 | 系统自动 | ❌不填 | 创建单据时刻自动记录，永久不变 |
| 提交时间 | 系统自动 | ❌不填 | 单据提交后系统自动生成 |

### 作业明细行（一张单据可多行，至少1行可提交）

| 字段名称 | 录入方式 | 是否仓管填写 | 说明 |
| :--- | :--- | :--- | :--- |
| 操作类型 | 下拉选择 | ✅填写 | 库内增值作业类型（第一版仅支持下拉选择，暂不做扫码） |
| 数量/工时 | 数字输入 | ✅填写 | 单一字段，根据作业场景填写实物数量或人工工时 |
| 单位 | 系统自动 | ❌不填 | 选择操作类型后系统自动带出对应计量单位，无需人工维护 |
| 备注 | 文本输入 | ⚠️选填 | 记录作业异常、特殊作业说明 |

## 三、Web表单视图（电脑端录入）

### 1. 基础只读信息区

| 字段 | 取值方式 | 权限 |
| :--- | :--- | :--- |
| 作业单号 | 系统自动流水 | 只读 |
| 新增时间 | 创建单据自动取值 | 只读 |
| 提交人/提交时间 | 提交后系统自动生成 | 提交后只读展示 |

### 2. 表头可编辑区

| 字段名称 | 控件类型 | 操作说明 |
| :--- | :--- | :--- |
| 关联对象 | 下拉单选 | 入库/出库/其他订单三选一 |
| 关联单据号 | 扫码/手工输入 | 系统识别校验单据有效性 |
| 操作员 | 人员选择 | 整单唯一作业人员，一单对应一人 |

### 3. 作业明细多行录入区（核心）

支持新增行、删除行，最少保留1条明细方可提交；单位随操作类型自动带出

| 操作类型 | 数量/工时 | 单位（系统自动） | 备注 |
| :--- | :--- | :--- | :--- |
| 贴标 | 20 | 张 | - |
| 缠膜 | 5 | 托 | 托盘整体缠膜 |

操作按钮：【+新增作业行】【-删除选中行】

### 4. 附件上传区（选填）

图片/视频：按需上传，支持多文件批量上传，非必填项

页面按钮：【保存草稿】【提交】

**作业任务明细**：适配现场单手操作，仅展示作业必填字段，系统字段后台自动托管

### 1. PDA前台展示字段

| 区域 | 字段 | 操作方式 |
| :--- | :--- | :--- |

| 明细区 | 操作类型、数量/工时、单位（自动）、备注 | 下拉选择、数字录入、短文本 |
| 辅助区 | 图片/视频（选填）、操作员 | 拍照/录像上传、人员选择 |

新增时间、提交时间、提交人

## 五、统一业务规则（仓库终审版）

| 序号 | 业务规则（面向仓库） |
| :--- | :--- |
| 1 | 作业单号由系统自动生成，人工不可编辑、不可重复。 |
| 2 | 一张作业单可登记1条或多条库内作业明细，支持一单多作业。 |
| 3 | 一张作业单只对应一个操作员，仅登记该操作员完成的作业，多人作业需分别建单。 |
| 4 | 同一个入库/出库/其他订单，支持关联多张作业单，不同操作员独立建单作业。 |
| 5 | 关联对象固定三选一：入库订单、出库订单、其他订单。 |
| 6 | 数量/工时为单一字段，仓管统一录入数值；系统根据所选操作类型自动匹配展示对应计量单位，无需人工填写单位。 |
| 7 | 图片、视频为非必填作业凭证，仓管根据现场作业情况自主选择是否上传，支持多文件上传。 |
| 8 | 单据未提交、草稿状态下，可反复修改所有可编辑内容。 |
| 9 | 单据提交后，核心字段锁定，不允许直接修改，异常错误需走更正流程。 |
| 10 | 新增时间、提交时间、提交人均由系统自动记录，人工不可干预、不可修改。 |
| 11 | PDA为现场精简录入模式，系统自动字段无需仓管手工维护，适配现场快速录单场景。 |
